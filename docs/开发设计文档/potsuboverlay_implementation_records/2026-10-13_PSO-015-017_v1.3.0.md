# 工作包 PSO-015 ~ PSO-017：PotSubOverlay v1.3.0

## 基本信息

- 日期：2026-10-13
- 状态：已完成，未发布（开发分支 `dev/v1.3.0`，版本号已升为 1.3.0，CHANGELOG 标记为「开发中」）
- 对应执行计划工作包：PSO-015 ~ PSO-017
- 来源：用户反馈——字幕显示 / 隐藏、无字幕、进出调整位置时的闪烁与跳位；动效只有开关；希望拖动进度条跳转

## 本次实现内容

- **过渡稳定（PSO-015）**：`OverlayWindow.runHidden` 握手（`overlay:prepare` → 页面淡出并等透明帧 → `overlay:prepared` → 改窗口 → 带 `reveal` 的 `overlay:mode` → 页面等到新尺寸布局完成再淡入）；`editing` / `shownEditing` 分离；退出编辑时传入生效位置；可见性不再包含编辑状态；位置变化在可见时走 runHidden；边界不变不 `setBounds`、高度 40px 取整；`SubtitleView` 改为单格 grid 底对齐叠放，去掉 `popLayout`；去掉字幕窗口内的 `backdrop-filter`。
- **动效（PSO-016）**：`style.motion`（6 种效果 + 时长、缓动、各效果参数、切换方式、合并短暂停顿、显示 / 隐藏过渡）；`lineMotion` 生成 motion 属性；外观页「动效」分组与自动演示；设置 v4 迁移与校验；窗口底部为向下的过渡预留 `bottomInset`。
- **进度条（PSO-017）**：`SeekBar` 组件（悬停加粗 + 圆点 + 时间气泡、拖动、松开跳转、等待落点、方向键）；`player:seek` IPC 与 `Controller.seekToTime`；播放页与简洁模式接入。
- **开发工具**：`POTSUB_USER_DATA` 单独设置目录（同时隔离单实例锁）；QA 步骤 `overlayEval`、`quiet`、`seek`。

## 关键决策

- 不再用固定延时等待窗口改尺寸：Chromium 在透明窗口改尺寸后的首帧时机不确定，由页面确认「已全透明」和「已按新尺寸布局」两个时刻最可靠。
- 换句用 grid 叠放而不是绝对定位：容器仍有高度，回看的上一句、提示等依旧排在字幕上方。
- 系统「减少动态效果」不再关闭换句动效。开发机（即用户的电脑）关闭了 Windows 动画效果，Chromium 报告 `prefers-reduced-motion: reduce`，1.2.1 的「切换动画」实际一直未生效；新版效果是应用内的显式选择，「无」即可关闭。
- 进度条只在松开时跳转，不在拖动中连续发送：避免频繁跳转打乱落点检查，也不给 PotPlayer 造成负担。
- 合并短暂停顿放在渲染层（按文本 key 计时），主进程的显示逻辑和最近字幕列表不受影响。
