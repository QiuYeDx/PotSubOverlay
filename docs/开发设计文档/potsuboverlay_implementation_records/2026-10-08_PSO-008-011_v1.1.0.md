## 本次实现内容

- **通用双语**：语言表 `src/shared/languages.ts`（13 种语言 + other）；按文字系统分类，拉丁语系用功能词区分；slot 投票扩展到任意语言；文件名标记支持全部语言并能拆分 `scjp` / `chseng` / `简英双语` 等组合；按“主语言 / 第二语言”角色合成显示，`primaryLang` 设置默认中文；外观按角色设置，字体为空时按语言自动选择。
- **设置迁移**：`settings-migrate.ts`，版本升到 3；v1 的 `zh/ja` 样式与模式迁移到角色；仍为 1.0 默认值的字号 / 描边换成新默认值（30 / 24 / 1.5px）。
- **新默认值**：主语言 30px、第二语言 24px、描边 1.5px。
- **托盘菜单**：自绘透明窗口（预加载、按光标定位、失焦/Esc 关闭、键盘上下导航），沿用 shadcn DropdownMenu 结构与应用主题。
- **修复**：
  - 简洁模式无字幕时按钮不可点：舞台中的字幕层与占位文字改为 `pointer-events-none`，并把 chrome 放到最上层。
  - 显示/隐藏闪烁：字幕窗口不再 hide/show，改为页面内 motion 淡入淡出（从当前值可中断反向），并对窗口禁用 DWM 过渡动画。
  - 字幕窗口初始状态可能丢失：页面挂载后主动 `overlay:state` 拉取。
  - 字体下拉溢出：高度受 `--radix-popover-content-available-height` 约束，空间不足时翻到上方。
  - 标题栏“简洁”按钮右边距 10px → 6px（与上边距一致）；主题切换按钮右边距 24px → 11px（与下边距一致，参照 FusionKit 8c37d2b），同步到 qiuye-electron-template 的 `main`（02ac853）与 `electron-modern`（b0aef64）。
