# 工作包 PSO-018：平滑圆角与简洁模式独立透明窗口（v1.3.0）

## 基本信息

- 日期：2026-10-13
- 状态：已发布（v1.3.0，2026-10-13）
- 对应执行计划工作包：PSO-018
- 来源：用户反馈——简洁模式窗口外圆角太小，与预览区的内圆角间距不等；希望全应用适合的地方使用平滑圆角

## 本次实现内容

- **`rounded-smooth-*` 工具类**（`src/smooth-corners.css`，主页面与字幕窗口共用）：与 `@qiuyedx/smooth-corners` 的 `smoothCorners(r, 0.6)` 输出一致——该平滑度下曲线与半径无关，等于半径 ×1.6 + `corner-shape: superellipse(1.7775)`，放在 `@supports` 里，不支持时保留原半径。接受主题 token（`rounded-smooth-xl`）与任意值（`rounded-smooth-[24px]`、`rounded-smooth-[var(--plate-radius)]`）。`cn()` 扩展了 tailwind-merge，`rounded-*` 与 `rounded-smooth-*` 互相覆盖。
- **应用范围**：shadcn 的 Button / Card / Dialog / Popover / Select / Tooltip / Input / Alert，预览舞台、设置分组、播放页卡片、关于页、更新面板、快捷键录制器、字体选择器、托盘菜单（面板 12 = 菜单项 8 + 内边距 4）、调整位置工具栏、字幕底板。胶囊和圆形（`rounded-full`）不变。ScrollArea 视口同时继承 `corner-shape`。尺寸很小的元素降一档（28px 图标块用 md、24px 按钮用 sm），避免放大后的半径超过短边一半被浏览器压缩。
- **简洁模式独立窗口**：`ControlWindow` 在首次进入简洁模式时创建无边框透明窗口，加载 `index.html?view=compact`（无启动加载动画，页面背景透明）；之后隐藏保留。切换：旧页面淡出 → 等简洁页面发出 `window:compact-ready`（首次，最多 3 秒）→ 显示新窗口、隐藏旧窗口 → 向新窗口发 `window:compact`（淡入并刷新快照）。完整窗口不再改尺寸，最大化状态保留。
- **简洁面板**：窗口四周留 12px 透明边距放阴影；面板 24px 平滑圆角、8px 内边距，预览 16px（24 − 8），预览内 8px 处放 24px 高的胶囊；底栏两端的图标按钮改为圆形，贴合面板圆角。
- **状态同步**：`send()` 发给两个页面（设置、快捷键状态），快照只发给正在使用的页面（`sendActive`）；简洁页面通过 `storage` 事件跟随完整窗口的主题与界面语言。去掉了 `window:is-compact`（页面类型由 URL 决定）。
- **切回窗口时误弹提示**（发布后补入 v1.3.0）：Radix Tooltip 在每次 focus 时打开，而窗口重新激活时 Chromium 会把焦点还给最后点过的按钮。`TooltipTrigger` 现在只在 `:focus-visible`（键盘聚焦）时放行，否则 `preventDefault` 跳过 Radix 的打开逻辑。Electron 实测：鼠标点击后切走再切回，`:focus-visible` 为 false、不再弹出；Tab 聚焦仍会弹出。
- 关闭简洁窗口：开启「关闭到托盘」时隐藏；否则与关闭完整窗口相同（下次打开回到完整模式）。QA 的 `capture: "control"`、`js`、`eval` 作用于当前使用的窗口，`quiet` 也覆盖简洁窗口。

## 关键决策

- 不在原窗口里放大圆角：Windows 11 给有边框窗口的圆角（DWM）固定为 8px，只能选圆 / 小圆 / 直角；`SetWindowRgn` 没有抗锯齿；透明窗口不能用于完整模式（无法正常缩放、没有系统阴影）。所以简洁模式改为单独的透明窗口自绘面板。
- 用 CSS 工具类而不是到处包 `SmoothCorners` 组件：平滑度固定时 K 值是常数，纯 CSS 即可与组件结果一致，也能直接写在 shadcn 组件的类名里；尺寸会变的个别元素仍可用 `SmoothCorners observeSize`。
- 简洁窗口保留而不销毁：再次进入不用重新加载；代价是用过一次简洁模式后多一个渲染进程。
