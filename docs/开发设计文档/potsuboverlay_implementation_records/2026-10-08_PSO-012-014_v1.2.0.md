# 工作包 PSO-012 ~ PSO-014：PotSubOverlay v1.2.0

## 基本信息

- 日期：2026-10-08
- 状态：已完成，随 v1.2.0 发布（开发分支 `dev/v1.2.0`）
- 对应执行计划工作包：PSO-012 ~ PSO-014
- 来源：`docs/TODO.md` 中的 v1.2.0 候选 1 ~ 3

## 本次实现内容

- **播放控制**：`PlayerBridge` 增加 `seek / setPlaying / command`；控制器增加播放 / 暂停、重听这一句（连按往前）、后退 / 前进（连按累加）；跳转后逐次轮询判断落点，识别 PotPlayer 的「以关键帧定位」，前进不足时补发「下一关键帧」；字幕窗口顶部显示操作提示；播放页与简洁模式加入控制按钮。
- **回看**：纯函数模块 `subtitle/lines.ts`；`Ctrl+Alt+Up` 在当前字幕上方显示上一句（5 秒内连按往前）；快照 `history` 与播放页「最近字幕」列表（点击从该句播放）。
- **按程序的字幕位置**：`ForegroundTracker` + `kernel32` 绑定读取前台程序 exe 名；`placementProfiles` / `autoPlacement` 设置；编辑模式「用于」切换；设置页管理列表。
- **其他**：位置轮询超时 200ms → 80ms 并在无响应时跳过状态查询；播放中单次 0 读数忽略；字幕窗口靠近屏幕顶部时缩短高度而不是下移；快捷键设置分组。
- **开发工具**：模拟播放器支持暂停 / 跳转 / `keyframe` 模式（8s GOP，跳转期间先返回目标时间）；QA 步骤 `hotkey`、`foreground`、`follow`（找不到指定标题的 PotPlayer 窗口就退出，保证不操作用户正在使用的播放器）、`overlayJs`。

## 关键决策

- 默认快捷键：开发机上 `Ctrl+Alt+Space`、`Ctrl+Alt+R`（以及 W/A/F/M）已被其他程序注册，改为 `K`（播放 / 暂停）与方向键一组（←/→ 跳转、↑ 回看、↓ 重听）。
- 不由本应用修改 PotPlayer 的「以关键帧定位」：`WM_COMMAND 10265` 只能切换且读不到当前状态，改为检测后提示用户。
- 关键帧检测在换文件前保持：一次“看起来精确”的落点可能只是恰好靠近关键帧，不能据此撤销。
- 回看显示在当前字幕上方而不是替换它，避免读旧句时又错过正在播放的一句。
- 每个游戏的位置在编辑时显式选择「用于」，不会因为在游戏里调整过一次就悄悄只对这个游戏生效。
