## 本次实现内容

- 从 `qiuye-electron-template@electron-modern`（f75c624）初始化，保留模板历史，重命名为 PotSubOverlay。
- PotPlayer 适配：koffi 调用 user32；`0x5002/0x5004/0x5006` 读取时长、位置、状态；`0x6020` + `PostMessage` 获取完整路径，经字幕窗口的 `hookWindowMessage(WM_COPYDATA)` 接收；路径请求串行化。
- 播放监控：1s 发现实例、播放中 50ms 轮询、自动/手动选择实例、前台检测（PotPlayer 在前台时隐藏字幕）。
- 字幕引擎：同名匹配（含 `name.<tag>.ext`、`name.mp4.ext`）、编码识别、SRT/VTT/ASS/SSA/LRC 解析、ASS 特效过滤、YouTube 滚动字幕去重、按 slot 投票的中日语言识别、默认轨道选择、双语合成。
- 字幕窗口：透明、置顶（定时重申）、穿透、不抢焦点；编辑模式全屏拖动、宽度调整、居中吸附、多显示器、方向键微调。
- 控制面板：播放 / 外观 / 设置 / 关于，完整与简洁模式切换，实时预览，四语文案；托盘菜单、全局快捷键（录制器）、开机启动、首次关闭到托盘提示。
- 新图标、README、CHANGELOG、LICENSE、CI 与 Release 工作流。
- 开发工具：`subtitle:inspect`、`icons:build`、`POTSUB_FAKE_PLAYER` 模拟播放器、`POTSUB_QA_SCRIPT` 截图验收。

## 验证结果

执行环境：Windows 11 Pro 26200，Node.js 24.21.0（项目专用便携版），pnpm 8.7.0，Electron 41.10.3，PotPlayer 64 位。

```text
corepack pnpm typecheck     通过
corepack pnpm i18n:check    [i18n] Locale keys are aligned.
corepack pnpm test          20 passed
corepack pnpm release:dir   打包后的 PotSubOverlay.exe 识别真实 PotPlayer（paused / none-found）
corepack pnpm release:win   PotSubOverlay_1.0.0_x64.exe（96.4 MB）
```

结果：

- 真实素材抽样：DBD-Raws `.scjp.ass`（双语）、无标记双语 ASS、双语 LRC、单语 LRC/SRT、YouTube 滚动 SRT 均识别正确。
- 实测发现并修复：
  - electron-builder 24 + pnpm 不收集传递依赖与可选依赖 → 主进程打包 iconv-lite/chardet，koffi 平台包设为直接依赖并 `asarUnpack`，asar 16MB → 1.5MB。
  - 默认快捷键 `Ctrl+Alt+E/L` 在本机被占用 → 改为 `Ctrl+Alt+P/J`。
  - 模板布局中 `h-10` 占位在 flex 中被压缩 → 内容区改为 `pt-12`，外观页 sticky 预览覆盖标题栏条带。
  - 路由切换保留滚动位置 → 页面退出动画结束后归零。
  - 日文“二か国語”在简洁模式被截断 → 改为“両方”，并调整简洁模式控件宽度。
