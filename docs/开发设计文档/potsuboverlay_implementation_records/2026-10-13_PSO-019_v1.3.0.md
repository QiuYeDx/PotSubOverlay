# 工作包 PSO-019：托盘菜单阴影与打开闪烁（v1.3.0）

## 基本信息

- 日期：2026-10-13
- 状态：已发布（发布后补入 v1.3.0，重新构建安装包）
- 对应执行计划工作包：PSO-019
- 来源：用户反馈——托盘菜单阴影有明显的裁切痕迹；每次右键打开菜单都会闪一下，像出现了两次

## 原因

- **阴影裁切**：菜单面板的阴影是 `0 8px 30px`，向下延伸约 38px，而透明窗口只在四周留了 10px，阴影在窗口边缘被截断，露出方框。
- **打开闪烁**：菜单隐藏时窗口里还画着完整的菜单。Windows 重新显示窗口时先放出这最后一帧，随后页面收到 `tray-menu:open`，按 `key` 重新挂载面板、从不透明度 0 播放入场动画——于是菜单先完整出现、消失、再淡入。

## 本次实现内容

- 透明边距改为 24px（`TRAY_MENU_SHADOW_MARGIN`，主进程定位与页面内边距共用）；阴影改为两层：`0 1px 2px` 贴边阴影 + `0 8px 20px -4px` 柔和阴影，后者上 8px、左右 16px、下 24px，全部落在边距内。
- 关闭握手：`hide()` 发 `tray-menu:hide` → 页面 100ms 淡出，动画结束并等两帧（空帧已上屏）后回 `tray-menu:hidden` → `win.hide()`；最多等 250ms。淡出期间重新打开会取消隐藏。
- 面板只在 `open` 与 `hide` 之间显示，不再用 `key` 重新挂载；新状态到达时保持隐藏，入场动画只播放一次。
- 点击面板外的透明边距等同于点击菜单外部，会关闭菜单（边距变宽后避免挡住旁边的托盘图标）。
- QA：`trayMenu: false` 关闭菜单，`menuEval` 在菜单页取值；`quiet` 也作用于菜单窗口。
